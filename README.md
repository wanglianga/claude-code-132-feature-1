# 阳光社区 · 亲子旧物交换平台

社区亲子旧物交换活动的**报名撮合与现场核销**系统。不是单纯的报名列表，而是让每一件物品从 **提交 → 审核 → 撮合 → 预约 → 到场 → 核销 → 交换成功 / 无人交换 / 转捐 / 带回** 全程可追踪，并让社区工作人员、志愿者、家长、公益机构围绕同一件物品协同处理异常。

技术栈：Vue 3 + TypeScript + Pinia + Vue Router + Vite（纯前端，localStorage 持久化，无需后端）。

## 本地启动

```bash
npm install        # 安装依赖
npm run dev        # 开发模式，默认 http://localhost:5173
```

### Docker 一键启动

```bash
docker compose up --build -d   # 构建并后台启动，访问 http://localhost:8080
docker compose down            # 停止
```

镜像采用多阶段构建（Node 构建静态资源 + nginx 托管 SPA），也可单独使用：

```bash
docker build -t swap-meet .
docker run --rm -p 8080:80 swap-meet
```

其他命令：

```bash
npm run build      # 生产构建（输出 dist/）
npm run preview    # 预览生产构建，默认 http://localhost:4173
npm run typecheck  # vue-tsc 类型检查
npm run smoke      # 端到端冒烟测试（jsdom 模拟四角色完整流程，25 项断言）
```

## 功能地图（按角色）

- **家长**：报名新物品（孩子年龄、物品品类/成色/照片、是否消毒、期望换取类型、参考价值、可到场时间、是否接受公益捐赠）→ 我的物品（状态时间线全程追踪）→ 撮合中心（查看智能推荐、发起/接受/拒绝撮合）→ 入场凭证（核销码 + 摊位 + 入场时段，冻结时凭证失效）→ 争议协调（与社区围绕物品沟通；对方物品被冻结时四选一：继续交换 / 改为自由交换 / 等待替代物品 / 取消；必要时补充公益捐赠授权）。
- **社区工作人员**：物品审核（可交换品类放行、禁入品类驳回并填写原因；强化复核期家庭须走多角度照片 + 缺件说明的强化复核）→ 撮合管理（一键智能撮合：按年龄段、品类、价值区间、双方期望、摊位容量评分配对，强化复核期家庭不参与自动撮合；未匹配物品转入自由交换区）→ 现场总览（到场/成交进度、冻结组合、自由交换区现场登记、标记未到场）→ 异常处置台（缺席、实物不符、孩子反悔、价值争议、公益接收不足的协同办结；**实物冻结的现场复核 + 回滚**：按双方实际到场情况分别释放/保留预约时段与摊位、补偿摊位优先级、转人工调解、校验授权与接收能力后转捐）→ 活动总结（交换成功率、冻结/退回统计、未到场名单、捐赠去向、强化复核家庭名单、品类缺口）。
- **志愿者**：扫码核销台（输入/扫描核销码 → 核对照片与实物一致、破损情况、消毒确认 → 通过或转异常）；**拍照标记实物问题**（缺少关键零件须填缺件说明 / 与报名照片差异较大 / 消毒状态无法确认），标记后物品与关联撮合立即冻结、取物凭证失效；上报现场异常；确认预约组合交换完成。
- **公益机构**：查看待接收捐赠、确认接收（占用接收能力）或因能力不足拒收（自动生成异常交由社区协调其他去向）。

### 实物不符冻结与撮合回滚（本次新增）

1. **冻结**：志愿者在核销页发现家长带到现场的玩具缺关键零件、与报名照片差异大或消毒状态无法确认时，拍照存证并标记问题类型（缺件必须填写缺件说明）。物品状态变为「问题冻结」，关联撮合变为冻结，双方取物凭证失效，冻结摊位继续占位以防重复分配。
2. **原撮合对象四选一**：未被冻结一方在「争议协调」页选择：继续交换（需社区复核通过）、改为自由交换、等待替代物品（保留摊位时段）、取消。选择仅为意向，不能单方面改写结果。
3. **社区现场复核与回滚**：社区对照报名原始描述与照片给出复核结论，再按双方实际到场情况执行：
   - 一方已到场、另一方取消：到场方可**保留入场时段改约并补偿摊位优先级**，或释放时段转自由交换；双方均未到场则分别释放时段与摊位；
   - 问题物品复核不通过则带回并计入退回，组合解除后对方按其选择回自由交换区或保留预约等待替代物品，**问题物品不会再次进入自动撮合**；
   - 双方对物品价值有争议、无法达成一致时可**转人工调解**，调解期间维持冻结，任何一方不得单独改写交换结果；
   - 社区决定**转捐**时，系统同时校验「家长捐赠授权」（未授权需家长在争议协调页补充）与「公益机构剩余接收能力」，两项均满足才放行。
4. **强化复核与自动撮合限制**：同一家庭累计 ≥2 次现场复核不通过，后续报名自动暂停自动撮合（智能推荐与一键撮合均跳过，仍可现场自由交换/社区手动安排），待审核物品必须通过社区的强化照片复核（多角度照片、零件清单、成色、消毒四项核对）；活动总结页可查看限制名单并在连续无问题后恢复资格。

### 手工验证路径（建议按顺序体验完整生命周期）

1. **报名与审核**：`parent1` 登录 →「报名新物品」提交一件玩具 → 切换 `staff` →「物品审核」通过该玩具；`parent4` 的「电动机器人（返修后再次报名）」会显示强化复核提示，需点「🧾 强化复核」完成四项核对才能通过；普通队列中驳回「儿童感冒药」（药品）与「手持烟花棒」（危险品）并填写原因。
2. **撮合与预约**：`staff` →「撮合管理」→「一键智能撮合」（强化复核期家庭的物品会被跳过并在时间线留痕）→ `parent2` 登录「撮合中心」接受磁力片撮合 → `parent4` 接受后双方预约成功，自动分配摊位与入场时段 → 家长在「我的物品」查看入场凭证（核销码二维码）。
3. **现场核销与交换**：`volunteer` 登录 → 输入 `SW-1011` 核销儿童平衡车（勾选照片一致、无破损、已消毒）→ 对 `SW-1012` 点读笔点击「🧊 拍照标记问题并冻结」，选择「缺少关键零件」、填写缺件说明与情况说明后确认，撮合与凭证立即冻结；双方均核销通过的组合可在「现场总览」（`staff`）点「确认交换完成」。
4. **冻结回滚协同**：`parent1` 登录「争议协调」，对被冻结的轨道火车组合选择处置方式（如「等待替代物品」）→ `staff`「异常处置台」打开该冻结单：查看双方到场/授权/接收能力、填写现场复核结论、按对方选择与到场情况选择处置动作（取消保留时段+补偿优先级 / 转自由交换 / 等待替代 / 带回 / 转捐 / 转人工调解），填写处理结论后办结，验证物品状态、摊位容量与时间线变化。
5. **异常协同**：`volunteer` 在核销台对某物品上报「孩子现场反悔」→ `staff`「异常处置台」选择处理方案（带回/转自由交换区）并办结 → `parent` 端「争议协调」可看到处理记录并补充说明；`charity` 拒收捐赠会自动生成「公益接收能力不足」异常。
6. **捐赠与总结**：`parent4` 对无人交换的拼图「申请转捐」→ `charity` 确认接收（占用接收能力）→ `staff`「活动总结」查看交换成功率、冻结/退回统计、未到场名单、捐赠去向、强化复核家庭名单与品类缺口分析。
7. **阶段推进**：`staff` 各页面顶部的阶段条可将活动从「报名审核 → 撮合配对 → 现场活动 → 活动总结」逐步推进。
